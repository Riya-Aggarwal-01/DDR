# 📂 Departmental Document Repository (DDR)

A secure and centralized web-based application for managing departmental documents in educational institutions. The Departmental Document Repository (DDR) streamlines document storage, organization, retrieval, and access through role-based permissions, providing an efficient alternative to traditional document management practices.

---

## 📖 Project Overview

Educational institutions generate and manage a large number of documents such as notices, circulars, reports, accreditation files, meeting minutes, academic records, and departmental resources. Managing these documents manually or across multiple storage locations often leads to inefficiency, duplication, and difficulty in retrieval.

The **Departmental Document Repository (DDR)** is designed to provide a centralized platform where authorized users can securely upload, organize, search, preview, and download departmental documents. The system ensures organized document management while maintaining security through role-based access control.

- 🔐 Secure User Authentication

## 👤 User Roles

### 👨‍💼 Administrator
- Manage users
- Create and manage departments
- Manage folder structure
- Assign user roles and permissions
- Monitor overall repository

### 👨‍🏫 Head of Department (HOD)
- Upload departmental documents
- Organize folders
- View and manage departmental records
- Search and retrieve documents

### 👩‍🏫 Faculty
- Upload documents
- Access department documents
- Search and download files
- Preview uploaded documents
